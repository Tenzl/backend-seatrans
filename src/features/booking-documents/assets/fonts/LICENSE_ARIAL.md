# Arial (embedded PDF fonts)

`Arial.ttf` and `Arial-Bold.ttf` in this folder are copies of the Microsoft
Arial typefaces from a Windows installation (`C:\Windows\Fonts\arial.ttf` and
`arialbd.ttf`), bundled so Nest can embed them in booking-document PDFs on any
host without relying on system fonts at runtime.

Arial is a proprietary font. Redistribution outside this project may require a
Microsoft or Monotype license. For an OFL, metrically compatible alternative,
use Liberation Sans instead.
